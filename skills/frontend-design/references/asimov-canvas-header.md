# Asimov canvas orientation

Load for local workbench headers or breadcrumb changes in an Asimov project. The
project's declared design authority and current shared shell own the contract;
this is conditional alignment guidance, not a second design law.

## Establish ownership before composition

Inspect global navigation, the actual header primitive, route metadata, existing
breadcrumb/link wrappers and current consumers. Distinguish product identity,
local location, active workspace/dataset/task scope, lifecycle, lens/view and
utilities. Keep a single global brand owner when the authenticated canvas is
nested beneath it. Do not reinsert a duplicate lockup when that navigation is
collapsed. Standalone/auth/marketing surfaces may own their sole identity;
inspect their contract before removing it.

Use the existing header identity seam for route-owned location. Derive labels and
ancestors only from explicit owning route data and legitimate destinations;
URL splitting, sidebar groups, graph geometry and lineage do not establish
ancestry. Pages without known ancestors get their existing current title.
Unavailable or inaccessible object metadata cannot supply invented links or
expose names. Do not build a parallel route registry or semantic state store.

## Preserve the task

Keep one accessible page heading, a nonlinked current page with aria-current,
localized labels and real ancestor links through shared navigation primitives.
Keep scope, lifecycle, representation and selected detail distinct and reachable.
Remove repeated orientation banners while retaining search labels, dynamic
counts, guidance, forms and actions. Preserve embedded compositions.

Carry only context supported by the destination's existing route contract;
do not blindly forward search/hash fields or invent return paths. Navigation
must not save configuration, activate policy or execute work. Preserve existing
unsaved-change behavior rather than adding a promise or confirmation ceremony.

## Allocate and verify

Use current tokens and shared header allocation. Keep the fitting desktop row;
use the supported responsive allocation when required. Bound the title slot,
reserve utilities, retain the current page and an accessible full long label.
If real ancestor depth overflows, use an existing accessible menu with keyboard
access, Escape and focus return. A shallow supported trail does not require a
speculative overflow system. Do not clip required ancestors or force page panning.

Verify the real authenticated ancestor/return/reload path and absence of mutation,
then representative shared-shell consumers with their existing context and drawer.
Batch desktop, compact/short-height, long labels, localization, themes and keyboard
checks under the selected browser lifecycle. Retain failures; actual QuickE2E
exploration and model-free exported replay are separate results when requested.
Structural conformance and automated task completion do not measure human benefit.
